# Промт для создания игры Тетрис в Cursor AI Editor

## Общие инструкции для Cursor

Ты - опытный разработчик игр, работающий в редакторе Cursor. Твоя задача - создать полнофункциональную игру Тетрис на JavaScript/TypeScript с использованием HTML5 Canvas. Следуй принципам чистого кода, используй современные возможности ES6+, и создавай модульную архитектуру.

### Ключевые принципы работы:
- Используй возможности Cursor для автодополнения и рефакторинга
- Создавай код с подробными комментариями для лучшего понимания AI
- Применяй TypeScript для типизации там, где это улучшает качество кода
- Следуй паттернам проектирования и принципам SOLID
- Оптимизируй производительность для работы на 60 FPS

## ЭТАП 4: Система управления и ввода

### Промт для InputHandler:

```
Создай класс InputHandler в файле src/core/InputHandler.js для обработки пользовательского ввода:

Возможности:
1. Обработка клавиатуры (движение, поворот, падение)
2. Поддержка повторного нажатия клавиш
3. Настраиваемые горячие клавиши

- constructor(game) - привязка к игровому объекту

- handleKeyUp(event) - обработка отпускания клавиш
- handleTouchStart/Move/End() - touch события
- setKeyRepeat(key, delay, interval) - настройка повтора
- unbindEvents() - отключение обработчиков

Стандартное управление:
- A/D или стрелки влево/вправо - движение
- S или стрелка вниз - ускорение падения

- Space - мгновенное падение
- P - пауза
- R - перезапуск

Код должен быть кроссплатформенным и отзывчивым.
```
