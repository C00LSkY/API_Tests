# 🎮 Тетрис - Современная реализация классической игры

Полнофункциональная игра Тетрис, созданная с использованием современных веб-технологий.

## ✨ Особенности

- **Классическая механика Тетриса** с всеми 7 типами фигур
- **Адаптивный дизайн** для desktop и мобильных устройств
- **Плавные анимации** и эффекты
- **Система очков** с прогрессией уровней
- **Сохранение рекордов** в localStorage
- **Touch управление** для мобильных устройств
- **Система wall-kick** для корректного поворота фигур
- **Анимация очистки линий** с эффектами

## 🎯 Управление

### Клавиатура
- **←/→ или A/D** - Движение влево/вправо
- **↑ или W** - Поворот фигуры
- **↓ или S** - Ускоренное падение
- **SPACE** - Мгновенное падение
- **P или ESC** - Пауза
- **R** - Перезапуск (на экране окончания игры)

### Touch (мобильные устройства)
- **Свайп влево/вправо** - Движение фигуры
- **Свайп вверх** - Поворот фигуры
- **Свайп вниз** - Мгновенное падение
- **Короткое нажатие** - Поворот фигуры

## 🚀 Запуск проекта

### Требования
- Node.js 16.0+
- npm или yarn

### Установка и запуск
```bash
# Клонирование репозитория
git clone <repository-url>
cd tetris-game

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предварительный просмотр сборки
npm run preview
```

## 🎨 Система очков

- **Одинарная линия:** 100 × уровень
- **Двойная линия:** 300 × уровень  
- **Тройная линия:** 500 × уровень
- **Тетрис (4 линии):** 800 × уровень
- **Мягкое падение:** 1 очко за клетку
- **Жесткое падение:** 2 очка за клетку

Уровень повышается каждые 10 очищенных линий.

## 🔧 Технические детали

### Используемые технологии
- **Vanilla JavaScript (ES6+)** - основная логика
- **HTML5 Canvas** - отрисовка игры
- **CSS3** - стилизация интерфейса
- **Vite** - сборка и разработка
- **Web Audio API** - звуковые эффекты

### Ключевые алгоритмы
- **Wall-kick система** для корректного поворота у границ
- **Система "мешка"** для генерации случайных фигур
- **Оптимизированная отрисовка** с минимизацией операций Canvas
- **Плавная анимация** с использованием requestAnimationFrame

## 🎮 Игровые механики

### Тетромино
Реализованы все 7 классических фигур:
- **I** - Линия (голубая)
- **O** - Квадрат (желтая)
- **T** - T-образная (фиолетовая)
- **S** - S-образная (зеленая)
- **Z** - Z-образная (красная)
- **J** - J-образная (синяя)
- **L** - L-образная (оранжевая)

### Система вращения
- Матричный поворот на 90 градусов
- Wall-kick алгоритм с 5 позициями проверки
- Специальные правила для I-фигуры

### Очистка линий
- Анимация мигания заполненных линий
- Плавный сдвиг блоков вниз
- Поддержка очистки до 4 линий одновременно

## 🛠️ Разработка

### Команды NPM
```bash
npm run dev        # Запуск в режиме разработки
npm run build      # Сборка для продакшена
npm run preview    # Предварительный просмотр сборки
npm run test       # Запуск тестов (будет добавлено)
npm run lint       # Проверка кода ESLint
npm run format     # Форматирование Prettier
```

### Отладка
В режиме разработки доступен глобальный объект `window.tetrisApp` для отладки:

```javascript
// Получить состояние игры
console.log(tetrisApp.game.getGameState());

// Получить отладочную информацию
console.log(tetrisApp.game.getDebugInfo());

// Симулировать нажатие клавиши
tetrisApp.inputHandler.simulateKeyPress('ArrowLeft');
```
